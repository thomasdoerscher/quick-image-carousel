# Project Conventions

## Stack

- TypeScript with strict mode
- React 19, functional components only
- Tailwind CSS and colors

## Commands

- Lint `npm run lint:fix`


## User Stories

- As a user, I can images in a carousel
- As a user, I can see a list of thumnails for all available images
- As a user, I can view an image by clicking on a thumbnail
- As a user, I can navigated between images using "Next" and "Previous" buttons
- As a user, I can see important information about the image and its author
- As a user, I can view additional metadata about an image, such as the camera used or date the image was taken
